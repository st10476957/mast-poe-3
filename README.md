## Change Log

### Version 1.2.0 — November 2025
## Version Updates
- *Added separate files for each screen*  
  Improved project organization and maintainability by moving each screen into its own file.

### UI/UX Improvements
- *Updated Welcome Screen*  
  - Added a background image for a more engaging appearance.  
  - Simplified navigation with a single menu button for a cleaner design.

### Home Screen Enhancements
- Added a *button to navigate* to the *Add Item* screen.  
- Added a *button to navigate* to the *Filter* screen.  
- Implemented an *average price calculator* for each item category.

### Add Item Screen
- Created a *new Add Item screen* that allows users to add items directly within the app.

### Filter Screen
- Added a *new Filter screen* that lets users filter food items by different categories.

The app now offers a cleaner design, easier navigation, and improved functionality for adding and organizing items.
